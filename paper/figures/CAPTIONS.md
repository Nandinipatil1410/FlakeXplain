# Figure captions

Generated by `paper/figures/make_figures.py` from `reports/mdflaker-fresh-v0.8/` (results.json, robustness.json, diagnostics.json, posthoc_extra.json, labels_summary.json). Do not edit numbers by hand; re-run the script.

**Figure 1.** Study pipeline. Failed test executions from GitHub Actions CI logs give 1,659 candidate failures with rerun results in 8 projects. Each is rerun 30 times on the commit CI tested; a failure is flaky if at least one rerun passes and not flaky if all 30 fail (409 flaky, 883 not flaky, 367 unlabelled and reported). Feature sets B (MDFlaker's factors), F (failure evidence) and C (static test context, ET-BFC only) feed the compared models, which are evaluated time-ordered within project (E1, test n = 516, 171 flaky), leave-one-project-out (E2, n = 1,292, 409 flaky) and on unseen tests (E1 test failures whose test is not in training, n = 321, 91 flaky). The unseen-test subset and the strict-history variant are post hoc (dashed box and italic note). Source: `labels_summary.json`, `results.json`, `posthoc_extra.json`.

**Figure 2.** Labelled test failures per project (light) and the flaky failures among them (dark), with flaky/labelled counts and rate. Total 1,292 labelled, 409 flaky. Source: `results.json` (projects), checked against `labels_summary.json`.

**Figure 3.** MCC with the original flaky-frequency history (open markers, the frozen features) and with strict history, which counts only earlier workflow runs (filled markers), for MDFlaker (MDF-paper-int), KNN8 (KNN8-float) and ET-BF on E1, E2 and unseen tests. The strict-history runs and the unseen-test subset are post hoc analyses outside the frozen decision rule. On unseen tests under strict history, ET-BF reaches MCC 0.469 against −0.160 for MDFlaker and −0.128 for KNN8. Source: `robustness.json` R1_strict_history; original-history E1/E2 values equal `results.json`.

**Figure 4.** Per-project MCC on unseen tests under strict history (post hoc) for MDFlaker, KNN8 and ET-BF. Per-project subsets are small (n and flaky count on each row), so single-project MCC values are unstable; an MCC of 0 can mean the model predicted one class only. Source: `posthoc_extra.json` strict.unseen_E1_per_project.

**Figure 5.** Global SHAP ranking (mean |SHAP value|) of all 22 ET-BF features on the E1 test part (n = 516; trained on 776), with original history (orange) and strict history (blue, post hoc). Labels give the rank under original → strict history. The top feature moves from `flaky_frequency` to `own_test_file_changed`; `flaky_frequency` falls from rank 1 to 4. SHAP 0.51.0 TreeExplainer. Source: `robustness.json` R2_shap_E1.
